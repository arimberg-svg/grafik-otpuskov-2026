# График отпусков 2026

Отчёт по рознице сети «У Михалыча»: официальный график ЗУП (форма Т-7) рядом с датами из файлов магазинов.

**Открыть страницу:** https://arimberg-svg.github.io/grafik-otpuskov-2026/

В отчёте только **действующие** сотрудники магазинов на 14.09.2026: кассиры, РТЗ, кладовщики, СПК, продавцы-консультанты и менеджеры по работе с клиентами (МОП).

1. Пересечения отпусков: СПК + кладовщик и одинаковые должности в одном магазине
2. Календарь по магазинам (по одному магазину) с цветами должностей
3. Новые сотрудники без графика (дата приёма и плановый отпуск +6 месяцев)
