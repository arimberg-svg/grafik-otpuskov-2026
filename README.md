# График отпусков 2026

Отчёт по рознице сети «У Михалыча»: официальный график ЗУП (форма Т-7) рядом с датами из файлов магазинов.

Открыть страницу: https://arimberg-svg.github.io/grafik-otpuskov-2026/

В отчёте только сотрудники магазинов: кассиры, РТЗ, кладовщики, старшие продавцы-консультанты и продавцы-консультанты.

1. Магазины, где кладовщик и СПК (если в ЗУП не выделен — продавец-консультант) одновременно в отпуске
2. По каждому магазину календарь должностей с наложением официального и неофициального графиков
3. Сотрудники, у кого отпуск есть только в официальном графике или только в файле магазина
